# StickyNotes - Sistemas Distribuidos

Aplicación de notas adhesivas desarrollada para la práctica de Sistemas Distribuidos.

## Estructura del Proyecto

- `backend/`: API desarrollada con NestJS.
- `frontend/`: Cliente web desarrollado con Next.js.

## Instrucciones de Inicio

### Backend
```bash
cd backend
npm install
npm run start:dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
